# ZILBERSHLAG

The House of Zilbershlag — a private auction & sale site for fine art and rare collectibles.
Single-page static site (`index.html`), bilingual EN/HE, backed by Firebase (project `asfanut`).

- Deploy `firestore.rules` to the Firebase project.
- Hosted on Vercel; domain: zilbershlag.com

See `SETUP.md` for setup steps.
